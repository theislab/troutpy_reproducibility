# Validation of the Rayleigh diffusion test

`Simulating_data_for_diffussion_complex_3d.ipynb` simulates transcripts moving by different
models (Brownian 3D/2D, correlated walk, Lévy flight, uniform noise) in a 3D volume, images a
thin slice and measures how often each model passes the Rayleigh test (ED Fig. 5C-E). The
simulation code is in `troutpy_reproducibility.diffusion_simulation`.
